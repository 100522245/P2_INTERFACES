# Diseño y Usabilidad Web (Práctica 2) - Interfaces de Usuario

Práctica 2 de la asignatura **Diseño de Interfaces de Usuario (UC3M)**.

---

## Descripción

Proyecto enfocado en la arquitectura de información, maquetación adaptable multidispositivo y pruebas de usabilidad con múltiples versiones de navegación y visualización (Versiones A, B y C).

### Componentes:
* Sistema de registro y login responsivo.
* Gestión de catálogos y tarjetas de productos con animaciones sutiles.
* Validación estricta W3C y optimización de jerarquía visual.
